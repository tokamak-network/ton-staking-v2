# 인터랙티브 데모 세션 시나리오 (프론트엔드 데모)

이 문서는 프론트엔드 데모에서 제공하는 **인터랙티브 데모 세션**의 기대 동작을 설명합니다.

## 진입점
- 프론트 UI: **인터랙티브 데모 세션** 섹션  
- 옵션: **Single Challenger**, **Two Challengers**  
- 동작: **Start Demo Session** 버튼 클릭

---

## 시나리오 1: 단일 챌린저

### 기대 동작 흐름
1. DisputeGame이 시작됩니다.
2. 단일 챌린저가 참여합니다.
3. 챌린저가 분쟁을 승리합니다.
4. 사용자가 **Slash Operator** 버튼을 클릭하면 운영자(Slash Operator)가 처벌됩니다.
5. 슬래싱이 성공적으로 실행됩니다.
6. 승리한 챌린저가 보상을 수령합니다.

### 확인 신호 (예시)
- 게임 상태가 **Resolved**(해결됨)로 전환됨
- Operator가 슬래싱된 이벤트가 발생함
- 챌린저의 보상/크레딧이 정상적으로 수령됨

### UI 동작
1. **Start Demo Session** 버튼 클릭 시 한명의 챌린저가 DisputeGame에서 승리한 내용까지 진행
2. **Slash Operator** 버튼을 클릭 시 운영자 슬래싱 트랜잭션이 실행됩니다.  
3. 슬래싱 성공 후 Operator의 금액이 슬래싱되고 챌린저가 보상을 수령한 금액들이 UI에 반영됩니다.

---

## 시나리오 2: 두 명의 챌린저 (서브게임 승리)

### 기대 동작 흐름
1. DisputeGame이 시작됩니다.
2. 두 명의 챌린저가 서브게임에 참여합니다.
3. 두 챌린저 모두 서브게임에서 승리합니다.
4. 사용자가 **Slash Operator** 버튼을 클릭하면 운영자가 처벌됩니다.
5. 슬래싱이 성공적으로 실행됩니다.
6. 두 명의 승리한 챌린저 모두 보상을 수령합니다.

### 확인 신호 (예시)
- 게임 상태가 **Resolved**(해결됨)로 전환됨
- Operator가 슬래싱된 이벤트가 발생함
- 보상이 두 명의 승리 챌린저에게 정상적으로 분배됨

### UI 동작
1. **Start Demo Session** 버튼 클릭 시 두명의 챌린저들이 DisputeGame에서 승리한 내용까지 진행
2. **Slash Operator** 버튼을 클릭 시 운영자 슬래싱 트랜잭션이 실행됩니다.  
3. 슬래싱 성공 후 Operator의 금액이 슬래싱되고 챌린저들이 보상을 수령한 금액들이 UI에 반영됩니다.

---

## 현재 문제점 (Issue Statement)
- **Single Challenger** 시나리오는 정상적으로 완료됩니다.
- **Two Challengers** 시나리오는 기대대로 작동하지 않습니다:  
  Start Demo Session의 마무리가 되지 않고 있습니다.
  마무리가 되면 Ready로 변경됨
