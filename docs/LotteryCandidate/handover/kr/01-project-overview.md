# 1. 프로젝트 개요

[← 목차로 돌아가기](./README.md)

---

## 1.1 목적

LotteryCandidate는 **Tokamak Network의 DAO 거버넌스 스테이킹 시스템 위에 무손실 복권(Lossless Lottery) 메커니즘을 결합**한 스마트 컨트랙트 프로젝트이다.

사용자는 TON 토큰을 예치(스테이킹)하여 네트워크 시뇨리지(seigniorage) 보상을 받으면서, 동시에 라운드별 복권에 참여해 상금을 획득할 기회를 갖는다. **원금은 보존되며, 참가비(entry fee)만 리스크에 노출**되는 구조이다.

## 1.2 타겟 사용자

| 사용자 유형 | 설명 |
|-------------|------|
| **일반 스테이커** | TON을 예치하고 시뇨리지 보상을 받으면서 복권에 참여하려는 사용자 |
| **오퍼레이터** | LotteryCandidate를 생성하고 복권 추첨을 실행하며, DAO 위원회 활동을 수행하는 운영자 |
| **DAO 위원회** | Tokamak Network 거버넌스에 참여하는 위원회 구성원 |

## 1.3 핵심 기능

| 기능 | 설명 |
|------|------|
| **통합 스테이킹 관리** | 사용자별 예치금을 하나의 풀로 모아 `DepositManager`에 스테이킹. 내부 잔액(`_balances`)으로 개별 지분 추적 |
| **라운드 기반 복권** | 고정된 참가비를 내부 잔액에서 차감. 전액 수령 방식(Winner-Takes-All). 오퍼레이터가 추첨 실행 |
| **비례적 시뇨리지 분배** | `SeigManager.updateSeigniorage()` 호출 시 Coinage 토큰 총 공급량 증가분을 모든 예치자에게 잔액 비율에 따라 분배 |
| **출금 관리** | 출금 요청 → 대기 기간(글로벌 출금 딜레이) → 출금 처리의 2단계 프로세스 |
| **DAO 거버넌스 연동** | 위원회 멤버 도전, 은퇴, 안건 투표, 활동 보상 청구 기능 |

## 1.4 프로젝트 위치

이 프로젝트는 **TON Staking V3** 모노레포의 `lotteryCandidate` 브랜치에서 개발되었다.

- **모노레포:** `ton-staking-v2` (TON Staking V3 전체 시스템)
- **기능 브랜치:** `lotteryCandidate`
- **베이스 브랜치:** `ton-staking-v2`
- **관련 문서 디렉토리:** `docs/LotteryCandidate/`
