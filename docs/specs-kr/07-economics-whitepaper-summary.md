# Tokamak Economics Whitepaper V2 요약

## 개요

이 백서는 Tokamak Network의 경제 모델을 설명하며, **TON Staking V3**라는 새로운 성과 기반 보상 분배 모델을 소개합니다.

## 1. 검증 경제학 (Verification Economics)

### 1.1 블록체인 확장성 문제
- 이더리움은 탈중앙화와 보안을 우선시하지만, 이로 인해 처리량이 제한됨
- **Layer 2 롤업**이 표준 확장 솔루션으로 채택됨
- 롤업 종류:
  - **Optimistic Rollup**: 기본적으로 유효하다고 가정, 사기 증명(fraud proof)으로 검증
  - **ZK Rollup**: 각 배치에 유효성 증명 필요

### 1.2 Tokamak Network 생태계 구성요소

| 구성요소 | 역할 |
|---------|------|
| **시퀀서(Sequencer)** | 트랜잭션 수집, 정렬, 실행 및 L1에 상태 커밋 제출 |
| **검증자(Validator)** | L2 활동 모니터링, 사기 증명 제출 가능 |
| **TON DAO** | 프로토콜 파라미터 설정, 재무 관리, 거버넌스 |

### 1.3 리스크 완화 메커니즘

**RAT (Randomized Attention Test)**
- 검증자를 무작위로 선택하여 특정 L2 배치 검증 요구
- 응답하지 않거나 부정직한 검증자는 슬래싱 처벌
- 검증 회피가 지배 전략이 되지 않도록 설계

**Fast Withdrawal**
- 사용자가 챌린지 기간을 기다리지 않고 즉시 L1 자산 수령 가능
- 유동성 공급자가 자산을 선지급하고 수수료 수취

## 2. TON의 유틸리티

### 2.1 L2 보안 (3단계 구조)
- **Tier 1**: 공개 챌린지(사기 증명) 메커니즘
- **Tier 2**: 전담 검증자의 명시적 검증
- **Tier 3**: RAT를 통한 확률적 감사

**시퀀서 담보금 공식:**
```
D_sequencer = H_max × C_max + Δ_sequencer
```

**검증자 담보금 공식:**
```
D_validator = C_off + Δ_validator
```

### 2.2 L2 가스
- TON은 L2에서 트랜잭션 실행의 **네이티브 가스 토큰**
- L2 트랜잭션 볼륨 증가 → TON 수요 증가

### 2.3 DAO 거버넌스
- TON은 Tokamak Network의 **유일한 거버넌스 자산**
- 스테이킹된 TON 양에 따라 거버넌스 영향력 결정

## 3. 시뇨리지 (Seigniorage)

### 3.1 시뇨리지 생성
- 블록당 **3.92 TON** 고정 발행
- 연간 발행량: 약 **10,301,760 TON** (Merge 이후)
- 초기 인플레이션율: ~19%, 10년 후 ~7.3%, 50년 후 ~1.9%

### 3.2 TON Staking V3 핵심 규칙

| 규칙 | 내용 |
|------|------|
| **Rule 1** | 연간 시뇨리지 발행량 A는 고정 |
| **Rule 2** | DAO에 고정 비율 할당: `S_DAO = d × A` |
| **Rule 3** | L2 성과는 **Bridged TON** 양으로 측정 |
| **Rule 4** | 최소 스테이킹 요건: `T_i ≥ θ × B_i` |

### 3.3 시뇨리지 분배 공식

**총 L2 시뇨리지 (쌍곡선 포화 함수):**
```
y(x) = L × (x / (k + x))
```
- L: L2에 할당되는 시뇨리지 상한 `(1-d) × A`
- k: 반포화점 (y = L/2일 때 x = k)
- 성과 증가에 따른 **체감 수익** 적용

**개별 L2 시뇨리지:**
```
S_i = y(x) × (B̃_i / x)
```

**검증자/시퀀서 분배:**
```
검증자 j 보상: v_j = Σ (α × S_i / |V_i|)
시퀀서 i 보상: o_i = (1 - α) × S_i
```

## 핵심 요약

1. **TON은 다목적 자산**: 보안 담보, 가스 토큰, 거버넌스 자산
2. **V3는 성과 기반 분배**: Bridged TON을 기준으로 보상 분배 (단순 스테이킹 양 기반이 아님)
3. **체감 수익 구조**: 대형 L2의 과도한 보상 집중 방지
4. **RAT 메커니즘**: 검증자의 지속적인 모니터링 유도
5. **지속 가능한 경제 구조**: L2 성장 → TON 수요 증가 → 생태계 확장의 선순환
