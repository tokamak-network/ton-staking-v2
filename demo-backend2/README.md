# demo-backend2 - Interactive Challenger Demo

**Option 1: Simplified Challenger** 구현을 위한 백엔드 서버입니다.

## 🎯 Option 1 개요

사용자가 복잡한 VM 실행을 직접 하지 않고, 데모가 미리 계산한 **올바른 move 중에서 전략적으로 선택**해서 승리하는 방식입니다.

### 특징
- ✅ 사용자가 Challenger 역할로 직접 참여
- ✅ 전략적 선택 (공격 vs 방어) 가능
- ✅ VM 계산 복잡도는 데모가 처리
- ✅ 올바른 게임 플로우 보장
